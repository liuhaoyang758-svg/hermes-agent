# 垂直行业 Agent SaaS 平台产品文档

## 1. 产品名称

暂定名称：行业 Agent 工厂 / Vertical Agent Studio。

产品一句话介绍：帮助企业和 AI 服务商把业务流程、销售话术、数据接口和优秀员工经验配置成可运行的行业数字员工。

## 2. 产品定位

平台面向 B 端业务场景，提供 Agent 搭建、运行、运营和评估能力。用户不需要从零开发 Agent，只需要选择行业模板、导入业务资料、配置流程和 Skill，即可搭建销售助理、客服助理、顾问助理、运营助理、培训陪练等数字员工。

产品核心不是“问知识库”，而是“根据客户对话上下文判断业务场景，并调用正确 Skill 完成业务动作”。

## 3. 产品角色

### 3.1 平台管理员

- 管理平台套餐、行业模板、公共连接器、模型配置。
- 查看平台整体客户、用量、收入和运行状态。

### 3.2 服务商管理员

- 管理服务商自己的客户企业。
- 为客户复制行业模板、配置 Agent、交付上线。
- 查看客户活跃度、用量和续费风险。

### 3.3 企业管理员/老板

- 管理企业账号、成员、权限、业务流程和看板。
- 查看客户状态、销售跟进、Agent 效果和经营数据。

### 3.4 业务主管

- 管理团队话术、跟进规则、培训任务和质检标准。
- 审核 Agent 输出、优化 Skill、沉淀优秀案例。

### 3.5 一线员工

- 在工作台接收 AI 建议、客户摘要、回复话术、跟进提醒。
- 使用 Agent 查询报价、推荐方案、生成话术、记录客户状态。

### 3.6 新人/学员

- 使用陪练系统模拟客户对话。
- 查看 AI 评分和改进建议。

## 4. 核心产品结构

### 4.1 首页工作台

- 今日待办：待回复、待跟进、待审核、待补资料、待训练。
- 客户动态：新增客户、重点客户、流失风险、成交提醒。
- Agent 状态：运行中、异常、需人工确认、使用量。
- 快捷入口：创建 Agent、导入资料、配置 Skill、查看看板。

### 4.2 行业模板中心

功能目标：让服务商和企业快速从行业最佳实践开始，而不是从空白开始。

主要功能：

- 模板列表：跨境物流、教育培训、房地产、跨境电商、企业服务。
- 模板详情：适用行业、包含流程、Skill、字段、数据源、话术示例。
- 一键复制：复制为企业私有模板。
- 模板版本：支持升级、回滚、对比差异。
- 私有模板：服务商可创建自己的行业模板。

### 4.3 Agent 管理

功能目标：创建面向岗位或任务的数字员工。

Agent 类型示例：

- 销售助理 Agent。
- 客服售后 Agent。
- 报价推荐 Agent。
- 课程顾问 Agent。
- 置业顾问 Agent。
- 新人陪练 Agent。
- 质检复盘 Agent。

主要配置项：

- Agent 名称、头像、角色说明。
- 所属行业模板。
- 可用 Skill。
- 可访问数据源。
- 可接入渠道。
- 自动化级别：仅建议、半自动、自动执行。
- 转人工规则。
- 风险控制规则。

### 4.4 Skill 中心

功能目标：把业务能力拆成可复用技能。

Skill 组成：

- 基本信息：名称、描述、适用场景。
- 输入字段：客户消息、客户阶段、业务参数、历史记录。
- 处理逻辑：Prompt、规则、工具调用、工作流。
- 输出格式：客户回复、内部建议、结构化字段、下一步动作。
- 测试用例：真实聊天样本、期望输出、评分标准。
- 版本管理：草稿、已发布、历史版本、回滚。

常用 Skill 模板：

- 需求识别 Skill：识别客户意图和关键信息。
- 方案推荐 Skill：根据规则和数据推荐产品、课程、房源、渠道。
- 报价测算 Skill：读取价格表或接口生成报价。
- 异议处理 Skill：处理嫌贵、犹豫、对比竞品、不信任等问题。
- 跟进计划 Skill：生成下一次跟进时间、理由和话术。
- 资料收集 Skill：判断缺什么资料并生成补充清单。
- 陪练评分 Skill：对新人对话进行评分和反馈。

### 4.5 业务流程设计器

功能目标：让企业把客户生命周期配置成可执行流程。

核心能力：

- 阶段配置：新线索、已咨询、已报价、待跟进、已成交、售后中、复购中。
- 阶段字段：每个阶段需要记录哪些业务信息。
- 触发规则：当客户说某类话、超过多久未回复、报价后未成交时触发动作。
- 自动动作：生成回复、创建待办、更新客户状态、提醒主管、调用接口。
- 人工确认：报价、承诺、退款、合同、重要客户等动作需确认。
- 流程看板：按阶段查看客户数量和推进情况。

### 4.6 数据源中心

功能目标：把企业业务资料接入为 Agent 可调用的数据和工具。

数据类型：

- 知识文档：产品手册、课程介绍、楼盘资料、物流渠道说明、售后政策。
- 表格数据：报价表、房源表、课程表、库存表、客户名单。
- 接口数据：CRM、ERP、OMS、教务系统、房源系统、电商平台。
- 历史对话：销冠聊天记录、客服优秀案例、投诉处理案例。

主要功能：

- 上传、解析、字段映射。
- 数据预览、清洗、去重、校验。
- 数据同步周期配置。
- 数据权限和可用 Agent 配置。
- 数据调用日志。

### 4.7 对话工作台

功能目标：让员工在真实业务中使用 AI，而不是另开一个孤立工具。

工作台能力：

- 客户会话列表。
- 客户画像和历史摘要。
- AI 场景识别结果。
- AI 推荐回复话术。
- AI 推荐方案/报价/房源/课程。
- 一键复制或一键发送。
- 一键生成跟进计划。
- 一键更新客户阶段。
- 转人工、标记错误、反馈好坏。

### 4.8 客户与线索管理

功能目标：让对话产生业务数据，让管理者看见业务过程。

主要功能：

- 自动创建客户档案。
- 自动提取客户需求字段。
- 客户标签：高意向、价格敏感、急单、待补资料、已流失。
- 跟进记录和下一步计划。
- 漏跟提醒和超时提醒。
- 客户阶段漏斗。
- 与 CRM 同步。

### 4.9 新人陪练系统

功能目标：把销冠经验转化为新人训练场。

主要功能：

- 场景库：按行业、岗位、难度分类。
- AI 扮演客户：主动追问、质疑、砍价、犹豫、投诉。
- 新人自由对话。
- 实时提示或结束后点评。
- 评分报告：需求识别、专业度、信任建立、异议处理、推进成交。
- 主管后台：查看新人训练次数、得分趋势、薄弱场景。

### 4.10 质检复盘中心

功能目标：持续优化员工和 Agent 表现。

主要功能：

- 聊天记录抽检。
- 自动识别未跟进、回复慢、话术错误、承诺违规、关键信息漏问。
- 输出质检评分。
- 沉淀优秀话术。
- 将高质量案例一键转为 Skill 示例。

### 4.11 数据看板

功能目标：让企业看到 AI 对业务效率的提升。

看板指标：

- 客户量：新增咨询、有效线索、高意向客户。
- 效率：平均响应时长、报价时长、跟进及时率。
- 转化：咨询转报价、报价转成交、试听转报名、带看转认购。
- 管理：漏跟客户、超时客户、待补资料客户。
- AI 效果：AI 使用次数、采纳率、自动化完成率、错误反馈率。
- 成本收益：节省工时、节省培训时间、减少漏单金额。

### 4.12 计费与套餐

套餐建议：

- 试用版：限制成员数、Agent 数、Skill 数、会话量。
- 标准版：适合单企业使用，支持基础模板、数据源、工作台、跟进。
- 专业版：支持多渠道、陪练、质检、API 连接、更多用量。
- 服务商版：支持多客户管理、私有模板、交付看板、分销计费。
- 企业版：支持私有化部署、专属模型、专属连接器、SLA。

计费维度：

- 席位数。
- Agent 数。
- Skill 数。
- 会话量。
- AI token/调用量。
- 数据源容量。
- 渠道连接数量。
- 行业模板/技能包。

## 5. 用户核心流程

### 5.1 服务商交付客户流程

1. 新建客户企业。
2. 选择行业模板，例如跨境物流。
3. 导入客户报价表、渠道说明、优秀聊天记录。
4. 配置业务流程：询价、报价、跟进、异常处理。
5. 配置 Skill：报价查询、渠道推荐、异议处理、跟进提醒。
6. 创建销售助理 Agent。
7. 在工作台测试真实案例。
8. 邀请客户员工试用。
9. 根据反馈调整 Skill 和流程。
10. 上线并持续查看效果看板。

### 5.2 企业员工使用流程

1. 客户通过微信、企微、WhatsApp、网页等渠道咨询。
2. 系统识别客户意图和关键字段。
3. Agent 调用对应 Skill 和数据源。
4. 工作台展示推荐方案、回复话术和下一步动作。
5. 员工确认后发送给客户。
6. 系统自动记录客户状态和跟进计划。
7. 到期提醒员工继续跟进。

### 5.3 客户视角交互流程

客户并不需要直接登录平台。客户仍然通过原有渠道和企业沟通。例如客户问：“美国 5kg 普货多少钱？”系统在后台帮助员工完成识别、报价、话术生成和跟进记录。客户感受到的是企业回复更快、更专业、更稳定。

### 5.4 老板/主管管理流程

1. 打开经营看板。
2. 查看今日新增客户、待跟进客户、漏跟客户和高意向客户。
3. 查看各员工 AI 使用和客户推进情况。
4. 查看常见客户问题和转化瓶颈。
5. 优化 Skill、话术、流程和培训任务。

## 8. 产品差异化

- 不只做知识库，而是做业务流程和 Skill 编排。
- 不只面向单行业，而是通过行业模板复用到多个行业。
- 不只给客户自动回复，而是先做员工副驾，再逐步自动化。
- 不只交付一次，而是通过日志、质检、看板持续优化。
- 不只服务企业，也服务 AI 服务商，让服务商能规模化交付。

## 9. 关键体验要求

- 业务人员不需要懂技术，也能使用模板搭建简单 Skill。
- 服务商可以在 1 到 3 天内完成一个基础客户交付。
- 员工在工作台中看到的 AI 建议必须可直接复制或发送。
- Agent 的每一步判断必须可解释，便于企业信任和复盘。
- 系统必须允许人工纠错，并把纠错沉淀为下一次可复用规则。

## 10. 产品成功指标

- 新客户首次成功创建 Agent 时间小于 30 分钟。
- 首个业务流程上线时间小于 1 天。
- 服务商交付单客户平均时间小于 5 天。
- 员工 AI 建议采纳率超过 50%。
- 客户跟进及时率提升 50% 以上。
- 新人培训周期缩短 50% 以上。
- 一个行业模板复用到 5 个以上客户后仍能保持 70% 以上配置复用率。
