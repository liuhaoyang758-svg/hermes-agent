# 垂直行业 Agent SaaS 平台需求文档

## 1. 项目背景

教育、跨境电商、房地产、跨境物流、本地生活、企业服务等行业表面业务不同，但一线业务流程有很强共性：获客、咨询、需求识别、方案推荐、报价/匹配、异议处理、资料收集、跟进转化、成交交付、售后复购、员工培训。

传统 AI 落地容易陷入“上传资料做知识库”的误区，但真实 B 端业务不是简单问答，而是多个业务场景串联的执行过程。平台要解决的核心问题不是让 AI 背资料，而是把优秀员工的业务判断、沟通话术、操作步骤、跟进节奏沉淀为可配置、可复用、可评估的 Agent Skill。

本项目拟建设一个面向多行业的垂直 Agent SaaS 平台，帮助服务商或企业快速搭建行业数字员工，用低代码/配置化方式完成业务流程梳理、技能编排、渠道接入、数据连接、客户跟进、员工陪练和经营分析。

## 2. 项目定位

本平台定位为“面向 B 端业务场景的 Agent 搭建与运营平台”。

它不是通用聊天机器人，也不是单纯知识库系统，而是一个可以让企业把业务流程拆成场景、把场景沉淀成 Skill、把 Skill 部署到微信、企微、WhatsApp、网页、电话、CRM、ERP 等渠道的 SaaS 平台。

核心目标：

- 让 AI 能根据客户对话上下文判断业务场景。
- 让 AI 能调用正确的知识、表格、接口、CRM、订单、日程等工具。
- 让 AI 输出可执行的下一步动作，而不仅是自然语言答案。
- 让企业能够沉淀优秀销售/顾问/运营的经验，复制给新人和普通员工。
- 让服务商能够按行业模板快速交付客户项目，形成可规模化的 Agent SaaS 生意。

## 3. 目标客户

### 3.1 平台直接客户

- AI 服务商：为不同行业企业交付 Agent 项目，需要标准化平台提高交付效率。
- SaaS 厂商：希望在现有 CRM、ERP、教务、房产系统中加入 AI Agent 能力。
- 中小企业：希望快速搭建内部数字员工，降低人工成本和管理成本。
- 连锁/多门店企业：希望统一销售话术、客户跟进和新人培训。
- 行业咨询/代运营团队：希望把行业 Know-how 产品化，形成可复制交付方案。

### 3.2 典型行业

- 跨境物流：询价、渠道推荐、客户跟进、新人陪练、异常处理。
- 跨境电商：选品、上品、客服、售后、订单异常、广告优化。
- 教育培训：课程咨询、学员测评、试听邀约、续费跟进、老师陪练。
- 房地产：楼盘咨询、客户需求匹配、带看邀约、贷款测算、置业顾问培训。
- 本地生活：门店咨询、套餐推荐、预约排班、评价回访、会员复购。
- 企业服务：线索分级、方案推荐、报价、合同资料收集、售后工单。

## 4. 核心问题

### 4.1 企业侧痛点

- 业务知识分散在文档、Excel、聊天记录、老员工脑子里，难以复用。
- 新人培训周期长，离职后经验流失严重。
- 客户咨询响应慢，普通员工无法像销冠一样判断客户真实需求。
- 客户跟进依赖个人记忆和手工表格，漏跟、错跟、重复跟进常见。
- 老板难以实时看到客户处于哪个阶段、销售是否有效推进。
- AI 工具很多，但无法贴合业务流程，最终只停留在问答和写文案。

### 4.2 服务商侧痛点

- 每个客户都要从零调研、搭建、调 Prompt、接数据，交付成本高。
- 项目能力沉淀弱，做完一个客户很难复用到下一个客户。
- 缺少统一的 Skill 模板、行业模板、调试工具和效果评估体系。
- 客户上线后无法持续运营和优化，难形成长期 SaaS 收入。

## 5. 建设原则

- 业务流程优先：先拆业务场景，再配置知识库、工具和 Agent。
- Skill 原子化：把复杂业务拆成可复用技能，如询价、推荐、跟进、异议处理。
- 数据连接标准化：文档、表格、数据库、接口、第三方 SaaS 都应抽象为可调用工具。
- 人机协同：AI 先辅助员工，成熟后再逐步自动化；高风险动作必须人工确认。
- 行业模板化：沉淀教育、跨境、房产、物流等模板，提高交付效率。
- 全链路可追踪：每次识别、调用、回复、动作、结果都要留痕，便于复盘和优化。
- 可商业化计费：支持按企业、席位、用量、技能包、行业模板、AI 调用量收费。

## 6. 业务抽象模型

平台需要把不同行业统一抽象为以下模型：

### 6.1 行业模板

行业模板是一组默认业务流程、角色、字段、数据源、Skill 和看板。例如跨境物流模板包含询价、报价、跟进、异常处理；教育模板包含课程咨询、测评、试听邀约、续费。

### 6.2 业务场景

业务场景是客户对话或内部操作中的具体任务，例如“客户首次询价”“客户嫌贵”“客户要看房”“家长咨询课程”“客户投诉延误”。

每个场景包含：

- 触发条件：关键词、意图、客户阶段、业务状态。
- 输入信息：客户消息、历史记录、表格数据、接口数据。
- 判断逻辑：是否需要报价、推荐、跟进、转人工、补资料。
- 调用工具：知识库、Excel、API、CRM、日历、消息通道。
- 输出结果：回复话术、推荐方案、待办任务、客户状态更新。
- 风险控制：置信度、敏感词、权限、人审阈值。

### 6.3 Skill 技能

Skill 是 Agent 可调用的业务能力，既可以是提示词能力，也可以是工具调用能力，还可以是完整工作流。

常见 Skill：

- 客户需求识别 Skill。
- 报价/测算 Skill。
- 产品/课程/房源/渠道推荐 Skill。
- 异议处理 Skill。
- 跟进计划生成 Skill。
- 客户状态更新 Skill。
- 新人陪练 Skill。
- 质检评分 Skill。

### 6.4 数据源

数据源包括文档、FAQ、Excel、数据库、第三方接口、历史聊天记录、客户资料、订单记录、业务规则。知识库只是数据源之一，不应成为唯一中心。

### 6.5 Agent

Agent 是面向具体岗位或任务的数字员工，例如销售助理 Agent、教务顾问 Agent、房产顾问 Agent、物流报价 Agent、客服售后 Agent。

Agent 通过对话上下文判断当前场景，并选择合适 Skill 执行业务动作。

## 7. 功能需求

### 7.1 多租户与组织管理

- 支持企业注册、租户隔离、组织架构、部门、角色、成员管理。
- 支持服务商管理多个客户企业。
- 支持企业独立配置行业模板、业务流程、数据源和 Agent。
- 支持操作日志、审计日志、登录日志和权限变更记录。

### 7.2 行业模板中心

- 内置跨境物流、教育培训、房地产、跨境电商、企业服务等行业模板。
- 支持模板复制、修改、发布、下架、版本管理。
- 支持服务商创建私有模板，复用到多个客户项目。
- 模板内容包括业务流程、客户阶段、字段模型、Skill、话术库、数据源配置、看板指标。

### 7.3 业务流程建模

- 支持可视化配置客户生命周期，例如新线索、已咨询、已报价、待补资料、已成交、售后中。
- 支持为每个阶段配置触发条件、自动动作、提醒规则、转人工规则。
- 支持流程版本管理，避免修改流程影响线上运行。
- 支持按行业配置不同流程字段。

### 7.4 Skill 搭建与编排

- 支持创建 Skill，配置名称、描述、适用场景、输入参数、输出格式、可调用工具。
- 支持 Prompt 模板、变量、示例、Few-shot、结构化输出。
- 支持工作流编排：条件判断、工具调用、循环、人工确认、消息发送、CRM 更新。
- 支持 Skill 调试、测试集、效果评分、版本回滚。
- 支持 Skill 市场，服务商可售卖行业技能包。

### 7.5 数据源与工具连接

- 支持文档上传：PDF、Word、Markdown、TXT、网页链接。
- 支持表格上传：Excel、CSV、在线表格。
- 支持数据库连接：MySQL、PostgreSQL、SQL Server 等。
- 支持 API 连接器：CRM、ERP、OMS、教务系统、房源系统、物流系统、电商平台。
- 支持数据源权限控制，不同 Agent 和员工只能访问授权数据。
- 支持定时同步、增量同步、字段映射、数据质量检测。

### 7.6 对话渠道接入

- 支持网页聊天窗口、企业微信、微信公众号、微信客服、WhatsApp、Telegram、邮件、短信、电话转写等渠道。
- 支持内部销售工作台，让员工复制 AI 建议后回复客户。
- 支持外部自动回复模式，但高风险业务需转人工确认。
- 支持会话合并、客户识别、历史上下文读取。

### 7.7 客户管理与跟进

- 支持自动创建客户档案，记录来源、需求、预算、意向、阶段、标签。
- 支持从聊天内容中提取关键字段，例如目的国、重量、预算、面积、课程年级、采购数量。
- 支持自动生成跟进计划，到期提醒销售或顾问。
- 支持客户状态看板、漏跟提醒、高意向客户预警。
- 支持与现有 CRM 双向同步。

### 7.8 新人陪练与员工赋能

- 支持基于真实优秀聊天记录生成训练场景。
- 支持 AI 扮演客户，新人扮演销售/顾问，进行多轮实战演练。
- 支持按行业、岗位、难度选择训练主题。
- 支持评分维度：需求识别、专业度、异议处理、成交推进、合规表达。
- 支持主管查看员工训练记录和能力短板。

### 7.9 质检与复盘

- 支持自动分析员工与客户的聊天记录。
- 支持识别未回复、回复慢、未跟进、话术不规范、承诺违规、报价错误等问题。
- 支持输出改进建议和优秀案例。
- 支持把高转化聊天记录沉淀为新 Skill 或话术模板。

### 7.10 经营分析看板

- 支持按企业、部门、员工、渠道、行业场景查看数据。
- 指标包括询盘量、响应时长、报价量、跟进量、成交量、转化率、漏跟数、AI 使用量。
- 支持 Agent 效果指标：命中场景率、工具调用成功率、人工采纳率、自动化完成率、节省工时。
- 支持服务商视角查看客户活跃度、用量、续费风险和交付进度。

### 7.11 计费与商业化

- 支持套餐管理：基础版、专业版、企业版、私有化版。
- 支持按席位、Agent 数、Skill 数、会话量、AI 调用量、数据源数量、渠道数量计费。
- 支持服务商分销、客户代开通、用量统计、账单导出。
- 支持免费试用、用量预警、超额限流、余额扣费。

## 8. 典型行业需求示例

### 8.1 跨境物流

- 读取报价表、渠道规则、附加费规则。
- 根据目的国、重量、货物属性推荐渠道。
- 生成报价话术和替代方案。
- 自动记录询价客户并设置跟进提醒。
- 针对延误、丢件、清关等异常生成处理话术。

### 8.2 教育培训

- 根据家长咨询内容识别年级、科目、目标、预算。
- 推荐课程、老师、班型和试听时间。
- 自动跟进试听、报名、续费、转介绍。
- 新人顾问可通过 AI 陪练练习咨询转化。

### 8.3 房地产

- 根据客户预算、区域、户型、学区、通勤要求匹配房源。
- 生成带看邀约话术和购房方案。
- 记录客户阶段，提醒置业顾问跟进。
- 对接房源系统和贷款测算工具。

### 8.4 跨境电商

- 根据商品、订单、售后、平台规则回答客服问题。
- 辅助生成产品标题、详情、广告文案。
- 处理订单异常、物流延误、退款退货。
- 对接店铺、ERP、OMS、工单系统。

## 9. 非功能需求

### 9.1 安全与合规

- 多租户数据必须严格隔离。
- 支持敏感数据脱敏、权限控制、审计记录。
- 支持企业数据删除、导出和备份。
- 支持模型调用日志，但不得泄露客户隐私和商业机密。

### 9.2 稳定性

- Agent 运行、工具调用、消息发送、任务调度需要具备重试和降级机制。
- 高并发会话下仍需保证响应时间和任务队列稳定。
- 外部 API 失败时应进入待处理队列，而不是直接丢失。

### 9.3 可扩展性

- 行业模板、Skill、工具连接器、渠道连接器都要插件化。
- 支持从单企业 SaaS 扩展到服务商多客户管理。
- 支持后续增加语音 Agent、数字人、RPA、私有化部署。

### 9.4 可观测性

- 记录 Agent 的意图识别、Skill 选择、工具调用、输入输出、错误原因。
- 支持回放一次完整对话和执行链路。
- 支持 Prompt、模型、工具版本对比，定位效果变化原因。

## 10. MVP 范围

建议 MVP 不要一开始覆盖所有行业，而是先实现“通用平台底座 + 2 个样板行业”。

### 10.1 MVP 必做

- 多租户、账号、角色权限。
- 行业模板管理。
- 客户阶段和业务流程配置。
- Skill 创建、Prompt 配置、工具调用配置。
- 文档/Excel 数据源接入。
- Web 聊天工作台。
- 客户档案、跟进提醒、状态看板。
- 基础员工陪练。
- Agent 运行日志和效果统计。

### 10.2 MVP 样板行业

- 跨境物流：报价查询、渠道推荐、客户跟进、新人陪练。
- 教育培训或房地产：咨询识别、方案推荐、邀约跟进、新人陪练。

### 10.3 暂不做或后置

- 全渠道自动回复。
- 复杂语音电话 Agent。
- 高度定制化私有部署。
- Skill 市场交易系统。
- 多模型自动路由和复杂模型评测平台。

## 11. 成功指标

- 首个客户从导入资料到上线 Agent 的时间小于 3 天。
- 一个行业模板复用到第二个客户时，交付工作量下降 50% 以上。
- 客户咨询平均响应时间下降 60% 以上。
- 客户漏跟率下降 80% 以上。
- 新人达到独立接待标准的时间缩短 50% 以上。
- 员工对 AI 建议的采纳率超过 50%。
- Agent 场景命中准确率超过 80%，核心 Skill 工具调用成功率超过 95%。

## 12. 主要风险与对策

- 风险：过度强调知识库，忽略业务流程。对策：平台核心围绕场景、Skill、流程、工具调用设计。
- 风险：行业差异导致模板难复用。对策：抽象通用客户生命周期，并允许行业字段和 Skill 插件化。
- 风险：AI 回复不稳定。对策：结构化输出、测试集评估、人审阈值、版本管理。
- 风险：客户数据质量差。对策：上线前提供数据整理工具、字段映射、缺失项检查。
- 风险：服务商交付不可控。对策：提供标准交付流程、行业模板、调试工具和效果看板。
- 风险：企业不愿意自动回复客户。对策：先做销售副驾和内部助手，成熟后逐步开放自动化。
